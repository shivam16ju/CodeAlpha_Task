## 📌 Project Overview
This project is part of the **CodeAlpha Python Programming Internship**. The task was to create a basic Hangman game with a limit of 6 incorrect guesses using a predefined set of words. 

Instead of a standard command-line script, this project was elevated into a **fully functional Web Application** to demonstrate full-stack capabilities, professional UI/UX design, and asynchronous state management.

## ✨ Key Features
- **Modern UI/UX**: Built with a sleek dark-mode glassmorphism design and fluid background gradient animations.
- **Dynamic SVG Animations**: The Hangman figure draws itself dynamically in real-time as incorrect guesses are made.
- **Interactive Keyboard**: Features an on-screen visual keyboard that highlights correct and incorrect guesses, completely synchronized with physical keyboard inputs.
- **Secure Backend**: Uses Python and Flask sessions to securely manage game state and logic on the server without reloading the page.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/CodeAlpha_Hangman_Web.git
   cd CodeAlpha_Hangman_Web
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Flask server:**
   ```bash
   python app.py
   ```

4. **Play the game:**
   Open your web browser and navigate to `http://127.0.0.1:5000`
