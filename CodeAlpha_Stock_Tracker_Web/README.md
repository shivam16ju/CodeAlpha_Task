## 📌 Project Overview
This project is part of the **CodeAlpha Python Programming Internship**. The task was to build a simple stock tracker that calculates total investment based on manually defined stock prices.

To demonstrate advanced full-stack proficiency, this tool was upgraded from a basic script into a **Premium Financial Web Dashboard** that resembles a real-world trading platform, while strictly adhering to the internship's requirement of using a hardcoded backend dictionary for prices.

## ✨ Key Features
- **Financial Dashboard UI**: Features a sleek, responsive dark-mode aesthetic with glowing accents for portfolio valuation.
- **Asynchronous Execution**: Uses vanilla JavaScript and REST APIs to add and remove stocks dynamically without page reloads.
- **Robust Error Handling**: Prevents invalid quantity inputs on both the client and server side.
- **Real-Time Calculation**: The Total Investment Value automatically updates instantly as you buy and sell shares.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/CodeAlpha_Stock_Tracker_Web.git
   cd CodeAlpha_Stock_Tracker_Web
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Flask server:**
   ```bash
   python app.py
   ```

4. **Access the Dashboard:**
   Open your web browser and navigate to `http://127.0.0.1:5001`
